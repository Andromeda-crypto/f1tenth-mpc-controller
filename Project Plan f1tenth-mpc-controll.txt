 # Project Plan: f1tenth-mpc-controller

  ## The Goal in One Sentence

  Build a Model Predictive Controller that drives an F1TENTH-scale car around a track, beating a tuned Pure Pursuit baseline, with full math derivation and
  a side-by-side demo video.

  ———

  ## How the Project Is Chunked (Big Picture)

  Chunk A — Dynamics + Forward Sim        [Days 1-2]   "I can simulate a car"
  Chunk B — Pure Pursuit Baseline         [Days 3-4]   "I have something to beat"
  Chunk C — MPC Controller                [Days 5-9]   "I beat the baseline"
  Chunk D — Comparison + Writeup + Video  [Days 10-12] "It's portfolio-ready"

  Each chunk has sub-bits below. Don't move to the next chunk until the "done when" line is true.

  ———

  New concepts for you to study (in this order):

  1. What is a QP? (Boyd, 1 hour skim)
  2. Linearization of nonlinear dynamics (Jacobian) — likely familiar from the balancing robot
  3. Receding horizon / model predictive control (Borrelli textbook ch. 12, or any 20-min YouTube)
  4. cvxpy syntax (their "Getting Started" page)
  5. How to linearize-at-each-step (the standard MPC trick — re-linearize around current state, not a fixed operating point)

  ## Reference Implementations to Choose From (Pick ONE for C1)

  Search GitHub for f1tenth mpc. Pick whichever has:

  - Clean README
  - < 200 lines of core controller code
  - Uses cvxpy or OSQP (not CasADi, not ACADO)
  - Tested on F1TENTH Gym

  You'll read it, understand it, then write your own. Do not copy-paste.

  ## The Skip List (Reaffirmed)

  To finish in 2 weeks, you are not doing:

  - Dynamic bicycle model with tire slip — kinematic is enough
  - Nonlinear MPC — linearize is enough
  - ROS2 deployment — run as a Python script
  - Real hardware — defer to "Future Work" in README
  - Obstacle avoidance v1 — pure tracking first; obstacles only if you finish early
  - C++ port — Python is fine
  - Robust MPC / tube MPC — stretch goal only
